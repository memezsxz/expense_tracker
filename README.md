# 💰 Income Exchange

**[Income Exchange](https://income-exchange-memef-dev.streamlit.app/)** is a simple, easy-to-use expense tracking application that helps you manage your finances, organize your transactions, and understand your spending habits.

## ✨ Features

### 🏦 Account Management
- Create, edit, and delete accounts.
- View account balances and statistics.
- Track financial activity for each account.

### 🏷️ Category Management
- Create, edit, and delete transaction categories.
- Organize transactions into categories.
- View category statistics to understand your spending.

### 💸 Transaction Tracking
- Track your income and expenses.
- Browse transactions month by month.
- Easily review your financial activity.

### 📊 Simple & Intuitive Interface
- Clean, user-friendly design.
- Easy navigation between accounts, categories, and transactions.
- Visual statistics to help you understand your finances.

## 🛠️ Built With

- **Python** - Application logic
- **Streamlit** - Interactive user interface
- **Pandas** - Data management and analysis
- **Plotly** - Interactive charts and visualizations

## 🎯 Goal

Make personal finance tracking simple, organized, and accessible through an intuitive interface.
